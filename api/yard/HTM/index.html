    Public Instance Methods¶

    clear_working_memory() ¶

    Clear all nodes from working memory

    Marks all nodes as evicted from working memory (in database) and clears the in-memory cache. Nodes remain in long-term memory. - @return [Integer] Number of nodes cleared from working memory

    @example 

    htm.clear_working_memory  # => 5

    forget(node_id, soft: true, confirm: false) ¶

    Forget a memory node (soft delete by default, permanent delete requires confirmation)

    By default, performs a soft delete (sets deleted_at timestamp). The node remains in the database but is excluded from queries. Use soft: false with confirm: :confirmed for permanent deletion. - @param node_id [Integer] ID of the node to delete - @param soft [Boolean] If true (default), soft delete; if false, permanent delete - @param confirm [Symbol] Must be :confirmed to proceed with permanent deletion - @raise [ArgumentError] if permanent deletion requested without confirmation - @raise [HTM::NotFoundError] if node doesn't exist - @return [Boolean] true if deleted

    @example Soft delete (recoverable) 

    htm.forget(node_id)
htm.forget(node_id, soft: true)

    @example Permanent delete (requires confirmation) 

    htm.forget(node_id, soft: false, confirm: :confirmed)

    forget_content(content_substring, soft: true, confirm: false) ¶

    Forget all nodes whose content includes the given string

    Performs a soft delete on all matching nodes. The nodes remain in the database but are excluded from queries. Use case-insensitive LIKE matching. - @param content_substring [String] Substring to search for in node content - @param soft [Boolean] If true (default), soft delete; if false, permanent delete - @param confirm [Symbol] Must be :confirmed to proceed with permanent deletion - @raise [ArgumentError] if content_substring is blank - @raise [ArgumentError] if permanent deletion requested without confirmation - @return [Array] Array of node IDs that were deleted

    @example Soft delete all nodes containing "deprecated" 

    htm.forget_content("deprecated")
# => [42, 56, 78]  # IDs of deleted nodes

    @example Permanent delete all nodes containing "test data" 

    htm.forget_content("test data", soft: false, confirm: :confirmed)

    initialize(working_memory_size: 128_000, robot_name: nil, db_config: nil, db_pool_size: 5, db_query_timeout: 30_000, db_cache_size: 1000, db_cache_ttl: 300) ¶

    Initialize a new HTM instance - @param working_memory_size [Integer] Maximum tokens for working memory (default: 128,000) - @param robot_name [String] Human-readable name for this robot (auto-generated if not provided) - @param db_config [Hash] Database configuration (uses ENV['HTM_DATABASE__URL'] if not provided) - @param db_pool_size [Integer] Database connection pool size (default: 5) - @param db_query_timeout [Integer] Database query timeout in milliseconds (default: 30000) - @param db_cache_size [Integer] Number of database query results to cache (default: 1000, use 0 to disable) - @param db_cache_ttl [Integer] Database cache TTL in seconds (default: 300) - @return [HTM] a new instance of HTM

    load_directory(path, pattern: '**/*.md', force: false) ¶

    Load all matching files from a directory into long-term memory - @param path [String] Directory path - @param pattern [String] Glob pattern (default: '**/*.md') - @param force [Boolean] Force re-sync even if unchanged (default: false) - @return [Array] Results for each file

    @example Load all markdown files recursively 

    results = htm.load_directory('/path/to/docs')

    @example Load only top-level markdown files 

    results = htm.load_directory('/path/to/docs', pattern: '*.md')

    load_file(path, force: false) ¶

    Load a single file into long-term memory

    Reads a text-based file (starting with markdown), chunks it by paragraph, and stores each chunk as a node. YAML frontmatter is preserved as metadata on the first chunk. - @param path [String] Path to file - @param force [Boolean] Force re-sync even if mtime unchanged (default: false) - @return [Hash] Result with keys: - :file_path [String] Absolute path to file - :chunks_created [Integer] Number of new chunks created - :chunks_updated [Integer] Number of existing chunks updated - :chunks_deleted [Integer] Number of chunks soft-deleted - :skipped [Boolean] True if file was unchanged and skipped

    @example Load a markdown file 

    result = htm.load_file('/path/to/doc.md')
# => { file_path: '/path/to/doc.md', chunks_created: 5, ... }

    @example Force re-sync even if unchanged 

    result = htm.load_file('/path/to/doc.md', force: true)

    nodes_from_file(file_path) ¶

    Get all nodes loaded from a specific file - @param file_path [String] Path to the source file - @return [Array] Nodes from this file, ordered by chunk_position

    @example 

    nodes = htm.nodes_from_file('/path/to/doc.md')
nodes.each { |node| puts node.content }

    purge_deleted(older_than:, confirm: false) ¶

    Permanently delete all soft-deleted nodes older than specified time - @param older_than [Time, ActiveSupport::Duration] Purge nodes soft-deleted before this time - @param confirm [Symbol] Must be :confirmed to proceed - @raise [ArgumentError] if confirmation not provided - @return [Integer] Number of nodes permanently deleted

    @example Purge nodes deleted more than 30 days ago 

    htm.purge_deleted(older_than: 30.days.ago, confirm: :confirmed)

    @example Purge nodes deleted before a specific date 

    htm.purge_deleted(older_than: Time.new(2024, 1, 1), confirm: :confirmed)

    recall(topic, timeframe: nil, limit: 20, strategy: :fulltext, with_relevance: false, query_tags: [], raw: false, metadata: {}) ¶

    Recall memories from a timeframe and topic - @param topic [String] Topic to search for (required) - @param timeframe [nil, Range, Array, Date, DateTime, Time, String, Symbol] Time filter - nil: No time filter (search all memories) - Range: Time range (e.g., 7.days.ago..Time.now) - Array: Multiple time windows (OR'd together) - Date: Entire day - DateTime/Time: Entire day containing that moment - String: Natural language (e.g., "last week", "few days ago") - :auto: Extract timeframe from topic query automatically - @param limit [Integer] Maximum number of nodes to retrieve (default: 20) - @param strategy [Symbol] Search strategy (:vector, :fulltext, :hybrid) (default: :vector) - @param with_relevance [Boolean] Include dynamic relevance scores (default: false) - @param query_tags [Array] Tags to boost relevance (default: []) - @param raw [Boolean] Return full node hashes (true) or just content strings (false) (default: false) - @param metadata [Hash] Filter by metadata fields using JSONB containment (default: {}) - @return [Array, Array] Content strings (raw: false) or full node hashes (raw: true)

    @example Basic usage - no time filter (returns content strings) 

    memories = htm.recall("PostgreSQL")
# => ["PostgreSQL is great for time-series data", "PostgreSQL with TimescaleDB..."]

    @example With explicit timeframe 

    memories = htm.recall("PostgreSQL", timeframe: "last week")
memories = htm.recall("PostgreSQL", timeframe: Date.today)
memories = htm.recall("PostgreSQL", timeframe: 7.days.ago..Time.now)

    @example Auto-extract timeframe from query 

    memories = htm.recall("what did we discuss last week about PostgreSQL", timeframe: :auto)
# Extracts "last week" as timeframe, searches for "what did we discuss about PostgreSQL"

    @example Multiple time windows 

    memories = htm.recall("meetings", timeframe: [last_monday, last_friday])

    @example Filter by metadata 

    memories = htm.recall("preferences", metadata: { source: "user" })
memories = htm.recall("decisions", metadata: { confidence: 0.9, type: "architectural" })

    remember(content, tags: [], metadata: {}) ¶

    Remember new information

    Stores content in long-term memory and adds it to working memory. Embeddings and hierarchical tags are automatically extracted by LLM in the background. - @param content [String] The information to remember (required, cannot be nil or empty) - @param tags [Array] Manual tags to assign (optional, in addition to auto-extracted tags) - @raise [ValidationError] If content is nil, empty, or exceeds maximum size - @return [Integer] Database ID of the memory node

    @example Remember with source 

    node_id = htm.remember("PostgreSQL is great for HTM")

    @example Remember with manual tags 

    node_id = htm.remember("Time-series data", tags: ["database:timescaledb"])

    @example Remember with metadata 

    node_id = htm.remember("User prefers dark mode", metadata: { source: "user", confidence: 0.95 })

    restore(node_id) ¶

    Restore a soft-deleted memory node - @param node_id [Integer] ID of the soft-deleted node to restore - @raise [HTM::NotFoundError] if node doesn't exist or isn't deleted - @return [Boolean] true if restored

    @example 

    htm.forget(node_id)        # Soft delete
htm.restore(node_id)       # Bring it back

    unload_file(file_path) ¶

    Unload a file (soft-delete all its chunks and remove source record in one transaction) - @param file_path [String] Path to the source file - @return [Integer] Number of nodes soft-deleted

    @example 

    count = htm.unload_file('/path/to/doc.md')
puts "Unloaded #{count} chunks"
